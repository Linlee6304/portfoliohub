PortfolioHub 登入連線修正

已重現的原因
原版前端預設代理到 https://localhost:7051，但目前後端運行在 http://localhost:5103。
Vite 因無法連線而回傳空白 502，前端將它顯示成「操作未完成，請稍後再試。」
此錯誤發生在登入請求抵達後端之前，不能據此判定密碼錯誤。

如何套用
將包內 client 資料夾合併到已套用天藍色首頁更新包的專案，覆蓋以下三個同名檔案：
client/vite.config.ts
client/src/api/axios.ts
client/.env.example

需要刪除的檔案：無。
不需更新後端、不需更動資料庫或帳號密碼。
這是修正包，不是完整專案。

套用後停止原先的前端開發程序，再於 client 執行 npm run dev。
後端可沿用目前已啟動的 http://localhost:5103。
新預設代理位址為 http://127.0.0.1:5103。
如果專案原先有 .env、.env.local 或 .env.development 中的 API_PROXY_TARGET，
該設定會優先於預設值；請確認它不是未啟動的 7051，必要時改為 http://127.0.0.1:5103。
若 VITE_API_BASE_URL 已被另外設定，應指向 /api 才會使用本地開發代理。

已確認
1. 修正前，透過前端呼叫登入 API 可重現空白 502。
2. 修正後，用瀏覽器送出不存在的診斷帳號，實際後端回傳 404「帳號不存在」。
3. 在隔離測試中模擬後端未啟動，代理回傳 JSON 503，畫面顯示「服務目前無法連線，請稍後再試。」
4. 後端 500 的訊息會顯示「服務處理發生錯誤，請稍後再試。」
5. npm run build 與 npm run lint 通過。

沒有使用你的真實帳密測試，沒有建立測試帳號或修改實際資料庫。
請用原帳號登入；若仍失敗，回報新的確切訊息即可，不需提供密碼。
